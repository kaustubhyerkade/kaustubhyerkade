## 👨‍💻 About Me

I'm a DevOps Engineer passionate about automation, cloud infrastructure, platform engineering, and continuous improvement.

I specialize in designing and maintaining CI/CD pipelines, managing cloud infrastructure, automating deployments, and improving the reliability and scalability of enterprise applications.

My engineering interests extend beyond traditional DevOps into cloud-native technologies, observability, infrastructure automation, and Generative AI.

I also enjoy writing technical blogs and sharing practical knowledge with the engineering community.

- ☁️ Working with cloud platforms and infrastructure automation.
- ⚙️ Building CI/CD pipelines and deployment workflows.
- ☸️ Exploring Kubernetes and cloud-native architecture.
- 📊 Implementing centralized logging and observability.
- 🤖 Exploring GenAI, LLMs, and RAG-based applications.
- ✍️ Writing technical articles and implementation guides.
